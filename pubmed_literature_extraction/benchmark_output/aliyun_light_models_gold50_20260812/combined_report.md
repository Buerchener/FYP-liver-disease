## 结论

1. `deepseek-v4-flash` 在这一固定候选集上同时取得最高语义关系 F1、最高严格写入 F1 和最低墙钟时间，是当前最佳裁判模型。
2. `qwen-flash` 是阿里模型中最均衡的轻量方案：语义 F1 最高、Evidence IoU 最高、输出 token 最少；适合作为低成本备用或 A/B shadow 模型。
3. `qwen3-30b-a3b-instruct-2507` 的严格写入 F1 接近 DeepSeek，但语义召回明显较低，表现为更偏写入门禁而不是完整关系裁决。
4. `qwen3.5-flash` 和 `qwen3.6-flash` 在当前结构化裁判提示上没有带来质量提升；前者尤其存在长尾延迟和输出 token 膨胀。
5. 自定义 MaaS 工作空间没有暴露可核验的单模型价格，因此不编造费用；表中保留实际 token 用量用于后续按账单单价换算。
